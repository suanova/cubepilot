CubePilot installed.

Components:
  operator  {{ .Values.operator.name }}   (control plane, leader election)
  api       {{ .Values.api.name }}        (REST/SSE + metadata store)
  web       {{ .Values.web.name }}        (Vue SPA, nginx)

Access the portal:
  kubectl -n {{ .Release.Namespace }} port-forward svc/cubepilot 8080:8080
  open http://127.0.0.1:8080

Notes:
- Platform CRDs are installed from the chart crds/ dir at first install.
  Helm does NOT upgrade CRDs; update them by reapplying the manifests in
  deploy/charts/cubepilot/crds/ after a chart upgrade.
- The openclaw-config and agent-kubeconfig secrets are created by
  scripts/setup.sh from caller-supplied inputs (CUBEPILOT_MODEL_PROVIDERS and
  an auto-generated or pinned CUBEPILOT_GATEWAY_TOKEN) -- no host OpenClaw
  config is read.
